# Lingo

[Português](#português) · [Italiano](#italiano) · [English](#english)

Plataforma para aprender idiomas com lições curtas, áudio e trilha por nível. O mascote é o Lino, um papagaio brasileiro.

---

## Português

O Lingo ensina **inglês, espanhol, francês, italiano e alemão**, do **A1 ao C2** (QECR). A interface do aluno está em português.

### O que o aluno faz

- Lê uma introdução e ouve só o idioma que está estudando.
- Responde exercícios de escolha, verdadeiro ou falso, completar, tradução, ordem e pares.
- Fala a frase no idioma de estudo. O Lingo compara o que ouviu e mostra se ficou certo, quase ou se vale tentar de novo.
- Avança na trilha ao concluir a lição (pelo menos 70% de acertos).
- Troca de idioma sem perder a conta. Um plano vale para todos os cursos.
- Entra com e-mail, Google ou Facebook. A foto pode ser um envio próprio ou um avatar do Lino.

O plano gratuito inclui os idiomas. Os planos pagos começam no Bronze, a partir de R$ 9,99 por mês.

### Requisitos

- PHP 8.1 ou mais novo
- MySQL ou MariaDB
- Apache (XAMPP no computador, ou cPanel na HostGator)

### Instalar no XAMPP

1. Coloque esta pasta em `C:\xampp\htdocs\lingo`.
2. Ligue Apache e MySQL.
3. Copie `config/config.exemplo.php` para `config/config.php` e ajuste o banco, se precisar.
4. Abra [http://localhost/lingo/install.php](http://localhost/lingo/install.php) e instale o banco e o conteúdo.
5. Defina a senha do admin em [http://localhost/lingo/admin/definir-senha.php](http://localhost/lingo/admin/definir-senha.php).
6. Abra [http://localhost/lingo/](http://localhost/lingo/).

Conta de demonstração: `demo@lingo.local` / `demo123`.

O arquivo `config/config.php` guarda senha do banco e chaves de login. Ele não vai para o Git. Use o exemplo e preencha no seu servidor.

Para publicar na HostGator, siga `INSTRUCOES-HOSTGATOR.md`.

## English

Lingo teaches **English, Spanish, French, Italian, and German**, from **A1 to C2** (CEFR). The student interface is in Portuguese.

### What the student does

- Reads a short introduction and hears only the language they are studying.
- Answers multiple-choice, true-or-false, fill-in, translation, word-order, and matching exercises.
- Speaks the phrase in the study language. Lingo compares what it heard and shows whether it was correct, close, or worth another try.
- Moves along the path after finishing a lesson (at least 70% correct).
- Switches language without losing the account. One plan covers every course.
- Signs in with email, Google, or Facebook. The photo can be an upload or a Lino avatar.

The free plan includes the languages. Paid plans start at Bronze, from R$ 9.99 per month.

### Requirements

- PHP 8.1 or newer
- MySQL or MariaDB
- Apache (XAMPP on a computer, or cPanel on HostGator)

### Install on XAMPP

1. Place this folder in `C:\xampp\htdocs\lingo`.
2. Start Apache and MySQL.
3. Copy `config/config.exemplo.php` to `config/config.php` and adjust the database if needed.
4. Open [http://localhost/lingo/install.php](http://localhost/lingo/install.php) and install the database and content.
5. Set the admin password at [http://localhost/lingo/admin/definir-senha.php](http://localhost/lingo/admin/definir-senha.php).
6. Open [http://localhost/lingo/](http://localhost/lingo/).

Demo account: `demo@lingo.local` / `demo123`.

`config/config.php` holds the database password and sign-in keys. It is not committed to Git. Use the example file and fill it in on your server.

To publish on HostGator, follow `INSTRUCOES-HOSTGATOR.md`.
