🌍 Lingo
Português: Aplicativo web completo para aprendizado de idiomas.
Italiano: Applicazione web completa per l'apprendimento delle lingue.
English: Comprehensive web application for language learning.

🇧🇷 Português
✨ Funcionalidades
📚 Cursos e Aulas: Estrutura organizada por idiomas, unidades e lições com teoria e exercícios.
🗣️ Vocabulário e Missões: Sistema de gamificação com missões e ranking para motivar o aprendizado.
💬 Conversas: Chat público e privado para interação entre alunos e tutores.
👤 Perfis e Planos: Gerenciamento de perfil de aluno, planos de assinatura e integração com OAuth.
⚙️ Painel Administrativo: Controle total sobre cursos, unidades, aulas, exercícios e usuários.

🛠️ Tecnologias
Backend: PHP (8.1+)
Frontend: HTML, CSS, JavaScript
Banco de Dados: MySQL
Outros: Python (ferramentas auxiliares), OAuth

🚀 Instalação
Ambiente Local (XAMPP)
Inicie os serviços Apache e MySQL no painel do XAMPP.
Clone ou extraia o projeto na pasta C:\xampp\htdocs\lingo.
Acesse http://localhost/lingo/install.php no seu navegador.
Configure o banco de dados: servidor localhost, porta 3306, banco lingo, usuário root (senha vazia ou root).
Clique em Instalar banco e conteúdo.
Defina a senha do administrador em http://localhost/lingo/admin/definir-senha.php.
Acesse o site em http://localhost/lingo/.
(Aluno demo: demo@lingo.local / Senha: demo123)
Produção (HostGator / cPanel)
No cPanel, defina a versão do PHP para 8.1 ou 8.2 (MultiPHP).
Crie um Banco de Dados MySQL, um usuário e conceda ALL PRIVILEGES. Anote o nome do banco e do usuário (com o prefixo da conta).
Faça o upload dos arquivos do projeto para public_html/ (ou public_html/lingo/).
Acesse https://seu-dominio.com/install.php e insira as credenciais do banco de dados.
Após a instalação, defina a senha do admin e apague o arquivo install.php do servidor por segurança.

🛠️ Technologies
Backend: PHP (8.1+)
Frontend: HTML, CSS, JavaScript
Database: MySQL
Other: Python (auxiliary tools), OAuth

🚀 Installation
Local Environment (XAMPP)
Start the Apache and MySQL services in the XAMPP control panel.
Clone or extract the project into the C:\xampp\htdocs\lingo folder.
Open http://localhost/lingo/install.php in your browser.
Configure the database: server localhost, port 3306, database lingo, user root (password empty or root).
Click on Install database and content.
Set the admin password at http://localhost/lingo/admin/definir-senha.php.
Access the site at http://localhost/lingo/.
(Demo student: demo@lingo.local / Password: demo123)
Production (HostGator / cPanel)
In cPanel, set the PHP version to 8.1 or 8.2 (MultiPHP).
Create a MySQL Database, a user, and grant ALL PRIVILEGES. Note the database name and user (with the account prefix).
Upload the project files to public_html/ (or public_html/lingo/).
Open https://your-domain.com/install.php and enter the database credentials.
After installation, set the admin password and delete the install.php file from the server for security.
